# Project Summary: Mutual Fund Analytics

## Overview
A Python-based data analytics project focused on mutual fund data ingestion, NAV analysis, data quality validation, and investment trend analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Requests
- Jupyter Notebook
- Git and GitHub

## Project Structure
- `data/raw/` — Raw datasets and API responses (excluded from Git)
- `data/processed/` — Cleaned and transformed datasets
- `notebooks/` — Data exploration and analysis
- `sql/` — SQL queries
- `dashboard/` — Dashboard development
- `reports/` — Analysis reports
- `data_ingestion.py` — Dataset inspection and quality validation
- `live_nav_fetch.py` — Fetches mutual fund NAV data from the API
- `requirements.txt` — Python dependencies
